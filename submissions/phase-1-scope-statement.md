## Inclusions

| System aspect                   | Justification                                                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Identity verification           | Core functionality for customers to securely access their account                                                    |
| Account summary                 | Core functionality to address customer demand on case transparency                                                   |
| Rule-based agent routing        | Core functionality to pipe self-service cases to portal                                                              |
| Eligible payment-plan selection | Addresses customers wanting to resolve debt independently where possible                                             |
| Promise-to-pay capture          | Reduces reliance on manual follow-up processes                                                                       |
| Account detail update request   | No direct measurable outcome, but a low-effort objective that contributes to a more complete self-service experience |

## Exclusions
| Exclusion                             | Justification                                                                                                  |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Specialist case handling              | Cases involving hardship, vulnerability will remain agent-led                                                  |
| Legal escalation                      | Involvement of external debt collection agencies regarding past-due debts can remain agent-led                 |
| Legacy collections system replacement | The solution aims to improve processes and capabilities rather than restructuring core operational systems     |
| Agent team resourcing                 | The solution is only concerned with process improvement -organisational efficiency requires further assessment |
